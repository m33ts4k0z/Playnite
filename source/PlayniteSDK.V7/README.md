# Playnite SDK 7

Playnite SDK 7 is the Avalonia-native plugin contract for Playnite's modern .NET applications. It targets .NET 10 and Avalonia 12 while retaining the UI-independent game, database, metadata, event, and plugin models from SDK 6.

SDK 6 remains available for existing WPF plugins. New SDK 7 plugins use Avalonia controls, converters, windows, dispatching, colors, and key gestures, plus asynchronous host APIs for dialogs, web views, game actions, and settings views.

This package is built from the Playnite source tree. See the [Playnite repository](https://github.com/JosefNemec/Playnite) for samples, issue tracking, and license information.
