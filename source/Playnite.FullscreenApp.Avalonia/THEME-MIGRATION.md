# Avalonia Fullscreen theme API 3.0

The theme API 3 author guide, including this shell's stable template parts and
audio asset contract, lives in the consolidated document:
[THEME-API-3.md](../Tools/Playnite.Toolbox/THEME-API-3.md).

Fullscreen specifics in short: `Mode: Fullscreen`, restart-applied packages via
`--theme` or the path persisted in `avaloniaFullscreen.json`; the stable
contract covers the `FullscreenMainView` control theme and optional
`audio/*` assets.
